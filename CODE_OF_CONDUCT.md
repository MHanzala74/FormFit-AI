# Code of Conduct

We want FormFit AI to be a welcoming project for everyone, regardless of experience level, background or identity.

## Our standards

- Be respectful and constructive, especially in code review and issue discussions
- Assume good intent; ask questions before criticising
- Give and accept feedback gracefully
- Keep discussions on topic and free of harassment, discrimination or personal attacks

## Enforcement

Unacceptable behaviour can be reported to the maintainer through a private GitHub message or a security advisory on this
repository. Maintainers may edit or remove comments, issues and contributions that violate this code, and may restrict
participation for repeated violations.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
